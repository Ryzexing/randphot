# RandomPhoto

Программа выбирает случайную фотографию из выбранной папки и всех вложенных папок.

## Обновления через GitHub

Программа проверяет новые версии в репозитории `Ryzexing/randphot`. Для публикации обновления:

1. Увеличьте `APP_VERSION` в `random_photo.py`.
2. Соберите `dist\RandomPhoto.exe`.
3. Создайте на GitHub новый Release с тегом вида `v1.0.1`.
4. Прикрепите к Release файл с точным именем `RandomPhoto.exe`.

Пользователь нажимает **«Проверить обновления»**. Если версия новее, программа скачает EXE, заменит старый файл и перезапустится.

Настройки сохраняются в `settings.json` рядом с EXE.
